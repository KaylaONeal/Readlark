# Readlark

Public support and privacy pages for Readlark, plus a mirror of the Kokoro-82M
voice model files used by the app (see Releases). App source is not published here.

- Overview: https://kaylaoneal.github.io/Readlark/
- Support: https://kaylaoneal.github.io/Readlark/support.html
- Privacy: https://kaylaoneal.github.io/Readlark/privacy.html

## Model files (Releases › models-v1.0)

`kokoro-v1.0.int8.onnx` and `voices-v1.0.bin` are unmodified copies of the
files published at https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0,
converted from Kokoro-82M by hexgrad (https://huggingface.co/hexgrad/Kokoro-82M),
licensed under the Apache License 2.0. See LICENSE-MODELS and NOTICE.
